## 2024-09-07 - Overly Permissive CORS and Error Leakage
**Vulnerability:** The FastAPI application used `allow_origins=["*"]` which is a critical security risk allowing any domain to interact with the API. Additionally, unhandled exceptions were returning raw error strings to the client, potentially leaking sensitive stack traces or internal implementation details. Finally, missing input length validations exposed the application to DoS attacks.
**Learning:** In fast-paced prototyping, security defaults like CORS and error handling are often bypassed for convenience. It's crucial to adopt defense-in-depth principles early: strict CORS origins, generic error messages with internal logging, and input bounds checking.
**Prevention:** Always restrict CORS to known trusted domains using environment variables. Catch all exceptions in endpoints, log them internally using `exc_info=True`, and return generic messages to the client. Enforce `max_length` on all string inputs in Pydantic models.
