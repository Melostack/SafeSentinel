## 2024-06-05 - FastAPI Security Enhancements: CORS, Input Validation, and Error Leaks
**Vulnerability:** The FastAPI application (`api/server.py`) contained multiple configuration-level security vulnerabilities: it used wildcard CORS (`allow_origins=["*"]`) which could permit unauthorized origin requests, lacked input constraints on Pydantic models (DoS risk via large payload strings), and directly returned unhandled exception trace strings to the client (`detail=str(e)`), risking sensitive internal detail leaks.
**Learning:** In fast prototyping with FastAPI, default behaviors like unbound Pydantic `str` types or returning stringified Exceptions are extremely common but pose immediate security risks in production, specifically exposing the application to DoS attacks and stack trace leakages.
**Prevention:** Always restrict CORS to environment-specific frontend URLs, enforce `Field(..., max_length=X)` on all Pydantic string fields, and catch exceptions by logging them internally with `exc_info=True` while returning generic HTTP 500 error messages to the client.
