## 2024-05-27 - Parameter Injection in API Connectors
**Vulnerability:** External API connector classes (like Binance and Bybit) were constructing query strings using manual string concatenation or f-strings (e.g., `f"coin={asset.upper()}"` and `'&'.join([f"{k}={v}" for k, v in params.items()])`). This can lead to parameter injection if user input is not properly sanitized, allowing attackers to manipulate the API request payload and potentially bypass signature validation or interact with unauthorized endpoints.
**Learning:** For all API connectors, query strings used for signature generation or request construction must be built using robust library functions like `urllib.parse.urlencode` (or equivalent) instead of manual string concatenation to properly handle URL encoding and prevent parameter injection.
**Prevention:** Enforce the use of `urllib.parse.urlencode` for all query string construction when interacting with external APIs, and ensure all dynamic parameters are properly encoded before being included in the request or signature payload.
