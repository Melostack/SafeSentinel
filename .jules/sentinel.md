## 2024-04-20 - Fix Overly Permissive CORS and Error Stack Trace Leakage
**Vulnerability:** The FastAPI server was configured with `allow_origins=["*"]` which allows any site to access the API endpoints (CORS vulnerability). Furthermore, the `/check` endpoint would expose full error details to users by returning `str(e)` in 500 HTTPExceptions (Information Leakage).
**Learning:** These vulnerabilities often exist because wildcard CORS is a quick way to bypass frontend connection issues during development, and passing `str(e)` to the HTTP response is an easy way to see errors in the frontend. Both expose the API and application internals to attackers.
**Prevention:** Always restrict CORS `allow_origins` to known trusted domains (e.g. read from `FRONTEND_URL` in `.env`). Never expose raw exception strings to the user in HTTP endpoints; instead, log the error on the server side with `logger.error(e, exc_info=True)` and return a generic error message like "Internal server error".
