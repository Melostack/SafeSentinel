## 2024-05-24 - DoS and Information Leakage via FastAPI Endpoints
**Vulnerability:** FastAPI endpoints (`/check`, `/extract`) used unbounded Pydantic string fields, creating a potential DoS vector through excessive input. Additionally, the `/check` endpoint exception handler raised a raw exception string (`detail=str(e)`), leaking internal stack traces. Finally, the API used overly permissive CORS headers (`allow_origins=["*"]`).
**Learning:** Pydantic `BaseModel` strings do not have default maximum lengths. Returning raw exceptions in HTTP responses frequently exposes sensitive information. Overly broad CORS configurations bypass browser security policies meant to restrict cross-origin requests.
**Prevention:** Always use `Field(..., max_length=X)` for string fields in Pydantic schemas. Use generic messages for client-facing errors while logging full stack traces internally using `logging.error(e, exc_info=True)`. Explicitly restrict CORS origins to trusted domains, using environment variables for dynamic configuration.
