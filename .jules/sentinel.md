## 2024-04-09 - [Multiple API Server Vulnerabilities (CORS, DoS, Error Leakage)]
**Vulnerability:** The API server had three distinct vulnerabilities: 1) Overly permissive CORS allowing all origins (`*`). 2) Unbounded Pydantic models lacking `max_length` limits, leading to potential DoS vulnerabilities. 3) Exception handlers leaked stack traces and internal errors to clients.
**Learning:** Default configurations for middleware, data validation models, and exception handlers in FastAPI are often insecure. These default templates bypass specific limits, generic error outputs, and origin checks which are required for production safety.
**Prevention:** For APIs interacting with untrusted networks, always constrain models using `Field(..., max_length=X)`. Set `allow_origins` strictly from secure, deployment-specific environment variables. Always implement generic external exception messages combined with internal full-trace logging (e.g. `logging.error(e, exc_info=True)`).
