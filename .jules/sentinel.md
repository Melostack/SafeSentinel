## 2024-06-15 - Secure FastAPI Implementation and API Request Handling Patterns
**Vulnerability:** Found permissive CORS (`allow_origins=["*"]`), missing length limits on user input in Pydantic models (DoS risk), leakage of internal error details via global exception handlers, and potential parameter injection risks via manual string concatenation for query parameters.
**Learning:** External API connections for Bybit and Binance APIs must use `urllib.parse.urlencode` to construct query strings for HMAC signature generation to prevent parameter injection. FastAPI endpoints serving the proxy must explicitly read frontend origin bounds from environment variables (`FRONTEND_URL`), string inputs need strict sizing via `pydantic.Field`, and generic exceptions must log with `exc_info=True` returning a generic failure instead of stringified exceptions.
**Prevention:** Follow secure coding patterns: always use `urlencode` to build HTTP parameters, validate input sizing for APIs (DoS protection), implement strict origin checks (CORS), and fail securely without leaking traceback details to consumers.
