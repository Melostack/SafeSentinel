## 2024-05-24 - [FastAPI Security Misconfigurations]
**Vulnerability:** Found multiple vulnerabilities in `api/server.py`: overly permissive CORS configuration (`allow_origins=["*"]`), missing maximum length limits for string fields in Pydantic models (DoS risk), and exception handlers that leaked raw stack traces (`detail=str(e)`).
**Learning:** Default configurations in FastAPI and Pydantic do not enforce strict security boundaries. Pydantic models without constraints allow unbounded memory consumption via large inputs. Similarly, raw exception strings expose internal application logic to attackers.
**Prevention:** Always restrict CORS origins to trusted domains using environment variables (e.g., `os.getenv("FRONTEND_URL").split(",")`). Enforce strict `max_length` limits on all user input in Pydantic models using `Field(...)`. Catch exceptions using `logging.error(..., exc_info=True)` for internal logging while returning generic, safe error messages to clients (e.g., "Internal server error").
