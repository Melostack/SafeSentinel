## 2024-05-23 - Prevent API Signature Forgery via Parameter Injection
**Vulnerability:** Constructing HTTP query strings manually via `&.join()` or direct string concatenation in API connectors (`BinanceConnector`, `BybitConnector`) allows for parameter injection (HTTP Parameter Pollution/Forgery), potentially bypassing authentication signatures. Additionally, reading the system time twice in `BybitConnector` causes a race condition where the signature payload and request headers use different timestamps, causing intermittent authentication failures.
**Learning:** Always use robust encoding libraries (like `urllib.parse.urlencode`) for building query strings to ensure parameters and values are safely URL-encoded. For authentication mechanisms involving timestamps, the exact same timestamp string must be generated once and reused across both the signature payload and the request headers.
**Prevention:** Enforce the use of standard URL encoding libraries for all HTTP requests and API signature generation. Audit all authentication flows to ensure timestamp variables are initialized exactly once per request.
