## 2024-05-18 - Parameter Injection and Timestamp Race Conditions in API Connectors
**Vulnerability:** API connectors (Binance and Bybit) were using manual string concatenation to build query strings for generating HMAC signatures, leading to potential parameter injection vulnerabilities. Additionally, the Bybit connector was re-generating timestamps within `_generate_signature` independently from the timestamp generated in the headers, leading to potential authentication failures due to race conditions.
**Learning:** Manual construction of query strings for cryptographic signatures or requests is highly prone to errors and injection risks. Also, when APIs require strict timestamp validation, using different timestamp instances for signature generation and request headers will lead to authorization failures under load or execution delays.
**Prevention:** Always use standard libraries like `urllib.parse.urlencode` to construct query parameters, which ensures proper URL encoding and mitigates parameter injection. In API authentications that rely on time, pre-generate a single timestamp string and pass it explicitly to both the signature generator and the request headers to ensure they are strictly identical.
